# 登录页封面图

把生成图保存为 `hero.jpg` 放在本目录即可，页面会自动使用它；文件缺失时回退到 `hero.svg`。

## 规格

- 尺寸：1200 × 1600（3:4 竖图）
- 格式：JPG 或 WebP，导出 JPG 时建议质量 85 以上
- 构图：上方适合放品牌字，下方三分之一留深色空间承载白色标题
- 不要出现文字、Logo、UI 控件、人物
