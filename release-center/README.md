# Regent 发布中心

本地发布管理页面，只监听 `127.0.0.1`，不会暴露到局域网或公网。

## 启动

双击 `start.command`，或执行：

```bash
./release-center/start.sh
```

默认地址：

```text
http://127.0.0.1:12600/
```

## 发布流程

1. 输入新版本号；
2. 可填写给 Codex 的补充要求；
3. 点击“生成版本内容”，由本机 Codex 只读分析仓库并生成摘要和更新项；
4. 审核并修改预览内容；
5. 勾选确认后点击“确认发布”；
6. 构建前端和双平台安装包，写入发布清单，并按选项部署公网。

发布流程不执行任何 Git 操作：不检查工作区、不创建标签、不推送 `origin`，
因此不需要 GitHub 登录或凭据。当前代码会直接进入安装包和发布内容。

生成成功的预览会写入 `~/.regent/release-center/draft.json`。刷新页面后会恢复版本号、
摘要、更新项和发布选项，不需要重新调用 Codex；“我已核对”勾选不会恢复，仍需人工重新确认。
发布成功后会清除草稿；如果生成后 Git 提交已经变化，发布中心会提示重新生成，避免发布旧内容。

发布页面支持：

- 同步部署公网前端；
- 实时查看构建与发布日志；
- 发布失败时保留日志并终止流程。

## 维护

```bash
./release-center/status.sh
./release-center/stop.sh
```

日志位置：

```text
~/.regent/logs/release-center.log
```
