| 项目 | 内容 |
|---|---|
| 需求编号 | REG-V105-MOB |
| 文档版本 | v1.4 |

## 一、决策原则

手机端只承担远程控制职责，不执行代码、不持有业务数据库、不接触项目工作区。

产品决策优先保证：

1. 用户离开电脑后仍然能下发任务、查看状态和处理决策。
2. 多账号之间不能串项目、串任务、串设备或串通知。
3. 任何状态都必须真实，离线不能显示成已执行。
4. 安全边界放在服务端，不能依赖 App 隐藏按钮。
5. 首版能够完成 Android 与 iOS 内测，并具备正式上架路径。

## 二、D-01 主机在线与离线通知

**决策**

- 公网中继增加“主机在线监测”能力。
- 执行电脑连接器持续向公网中继心跳。
- 连接器每 10 秒发送一次心跳，公网侧每 5 秒扫描一次状态。
- 连接器连续 60 秒无心跳判定为离线。
- 恢复心跳后稳定 30 秒才判定为在线，避免网络抖动导致反复通知。
- 离线、上线状态发生变化时，向该主机所属账号已订阅的手机发送推送。
- 手机 App 打开时同时读取当前主机状态，不依赖推送判断实时状态。
- 业务通知仍由本地 Regent 产生，包括等待决策、任务失败、疑似卡住和任务完成。
- 公网主机监测只保存运行状态、主机标识、账号订阅关系和推送令牌，不保存任务、项目、日志和文件。

**用户可见状态**

| 状态 | 含义 | 手机提示 |
|---|---|---|
| 在线 | 连接器和本地 Regent 均正常 | 正常 |
| 离线 | 60 秒内没有连接器心跳 | 主机离线，任务无法下发和执行 |
| 恢复中 | 心跳恢复但未满 30 秒稳定窗口 | 主机正在恢复连接 |

**不做**

- 电脑关机时不允许手机远程执行任务。
- 不通过公网中继保存任务队列。
- 公网中继自身不可用时，无法保证离线通知。

## 三、D-02 手机文件上传

**决策**

- 手机端支持图片和文档上传。
- 单份文档上限 25MB。
- 单个任务最多绑定 20 份文档。
- 使用分片上传，分片大小 2MB。
- 每份文件创建独立上传会话，记录文件摘要、总分片数、已完成分片和过期时间。
- 分片支持失败重试和断点续传，每个分片必须幂等。
- 全部完成后由服务端校验文件总大小和 SHA-256，再绑定任务或写入文件库。
- 上传会话默认 24 小时过期，过期后清理临时文件。
- Nginx 单请求上限保持至少 32MB，兼容整图上传；文档分片请求远小于该上限。
- 单次分片请求要求 60 秒内完成，慢网通过更多小分片重试，而不是延长一个超大请求。

**原因**

现有公网链路不适合让手机一次性上传数十 MB 文件。分片上传可以避免公网请求超时、
Nginx 默认请求体限制和断网后整份重传。

## 四、D-03 手机端认证

**决策**

- 手机 App 使用 Regent 正式账号登录。
- App 使用 Bearer 会话，不使用浏览器 Cookie 作为主要认证。
- Access Token 有效期 30 分钟。
- Refresh Token 有效期 30 天，每次刷新后轮换旧令牌。
- Access Token 和 Refresh Token 只保存哈希到服务端，App 只把明文保存到 Keychain/Keystore。
- Token 必须绑定账号和手机安装实例。
- Nginx Basic Auth 不作为 App API 的认证方式。
- 公网中继共享密钥只用于连接器通道，不能下发给手机。
- 写接口必须同时携带 App Bearer 会话和 `X-Regent-Relay-Request: 1`。
- 批准、驳回、撤销执行电脑和账号注销等敏感操作，要求短期操作令牌或生物识别后的再次认证。

**令牌规则**

| 令牌 | 有效期 | 作用 |
|---|---:|---|
| Access Token | 30 分钟 | 日常读取和普通操作 |
| Refresh Token | 30 天 | 轮换获取新的 Access Token |
| Step-up Token | 5 分钟 | 敏感操作二次确认 |

## 五、D-04 项目与执行电脑的关系

**决策**

- 一台执行电脑绑定一个账号。
- 一个项目与执行电脑之间必须建立显式授权关系。
- 执行电脑首次连接后，必须验证项目路径存在、目录可访问且 Codex 可用，才能授权该项目。
- 手机创建任务时，只能选择“项目授权有效、执行电脑在线、Codex 可用”的设备。
- 没有可用执行电脑时，任务只能保存为草稿或进入等待设备状态，不能显示为已派发。
- 项目授权失效后，设备不能继续认领该项目的任务。

**授权状态**

| 状态 | 含义 |
|---|---|
| 已验证 | 项目路径与 Codex 在当前电脑上可用 |
| 待验证 | 已建立授权，但尚未完成本机检查 |
| 不可用 | 路径不存在、目录不可访问或 Codex 不可用 |
| 已撤销 | 用户或账号策略停止该电脑执行该项目 |

账号、项目、执行电脑和授权的 `owner_id` 必须一致。

## 六、D-05 幂等

**决策**

- 新建任务、立即派发、加入队列、批准、驳回、停止、重试和撤销设备都必须携带客户端请求 ID。
- 服务端按 `user_id + clientRequestId` 保存幂等结果，默认保留 24 小时。
- 相同请求重复提交时返回第一次的业务结果，不重复创建任务或执行记录。
- 服务端保存请求摘要；同一 `clientRequestId` 携带不同动作或请求体时拒绝，不能复用旧结果。
- 上传分片使用 `uploadSessionId + chunkIndex + chunkHash` 幂等。
- App 自动重试必须复用原请求 ID，用户重新编辑任务后生成新请求 ID。

## 七、D-06 执行电脑配对

**决策**

- 执行电脑已登录账号 A 后生成一次性配对二维码。
- 二维码有效期 10 分钟，只允许绑定一次。
- 手机 A 扫码后，电脑端必须展示手机名称并要求本人确认“允许绑定”。
- 电脑端未确认前，手机只能看到“等待电脑确认”。
- 账号 B 扫码时统一提示“配对信息已失效”，不暴露电脑归属。
- 配对成功后生成设备凭据，凭据只保存哈希，支持轮换和撤销。

## 八、D-07 撤销执行电脑

**决策**

- 撤销后设备凭据、手机端心跳和待派发队列立即失效。
- 当前活跃执行记录收敛为 `INTERRUPTED`。
- 对应任务进入 `CANCELLED`，原因记录为“执行电脑已被撤销”。
- 任务不自动转移到其他电脑，用户确认工作区状态后可手动重试并选择新设备。
- 所有相关手机和电脑立即刷新设备状态。

## 九、D-08 生物识别与本地安全

**决策**

- 支持面容 ID、指纹或系统设备密码。
- 解锁 App 默认使用系统生物识别；设备不支持时回退到系统密码。
- 敏感操作始终要求再次认证。
- 首版把生物识别/系统密码解锁作为正式上架必须具备的能力，不再标记为可选。
- 生物识别失败不能无限重试，连续失败后要求重新登录账号。

## 十、D-09 账号注销

**决策**

- App 内提供账号注销入口。
- 注销前提示影响：项目、任务、执行电脑、文件库、决策和推送全部不可再访问。
- 注销要求重新登录验证和二次确认。
- 注销后撤销全部手机安装、执行电脑绑定和推送订阅。
- 审计与法务要求保留的数据按去标识化方式保留，其余业务数据按服务端策略处理。
- 注销流程必须可测试，不能只写在隐私政策里。

## 十一、D-10 平台和版本

**决策**

- iOS 最低版本：iOS 15。
- Android 最低版本：Android 9。
- iOS 内测：TestFlight。
- iOS 正式：App Store。
- Android 内测：签名 APK。
- Android 正式：签名 APK/AAB，官网与选定应用商店发布。
- App 内展示完整发布码，例如 `V1.0.5 · R100B001`。

## 十二、D-11 多账号边界

**决策**

- 同一账号可以拥有多台手机和多台执行电脑。
- 一台执行电脑只能绑定一个账号。
- 同一账号的多台手机可以同时操作，写操作必须幂等。
- 不支持跨账号共享、转交、代操作或管理员查看业务数据。
- 跨账号请求统一返回“对象不存在或已失效”。
- 账号切换必须清理旧账号的草稿、缓存、推送订阅和深链上下文。

## 十三、D-12 品牌标语

**决策**

- 固定产品标语为“电脑不在身边，AI 任务随时随地开工”。
- 首页首屏展示标语，位置在首页标题与主机状态之间。
- 标语表达“通过手机远程下达和控制 AI 任务”的产品定位，突出电脑不在身边也能继续工作。
- “随时随地”只描述手机控制端，不得暗示执行电脑关机、断网或休眠时仍能运行。
- 不使用“无人值守”“完全自动决策”等会造成错误预期的表述。
- 商店介绍、启动页、关于页和发布材料沿用同一标语。

## 十四、决策对需求文档的影响

以下原待确认项已经关闭：

- 主机离线通知责任方：公网侧在线监测负责主机状态推送，本地 Regent 负责业务通知。
- 文件上传方案：25MB 上限、2MB 分片、断点续传、24 小时上传会话。
- 手机认证方案：Bearer + Refresh + Step-up Token，不使用 Basic Auth 作为 App 认证。
- 项目与执行电脑关系：显式授权并验证项目路径与 Codex。
- 配对方式：二维码 + 电脑端二次确认。
- 生物识别：正式上架必须具备。
- 最低系统版本：iOS 15、Android 9。
- 账号注销：进入功能范围和验收范围。
