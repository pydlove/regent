# Regent 项目成员与角色设计

| 项目 | 内容 |
|---|---|
| 文档状态 | 第一版已实现 |
| 编写日期 | 2026-10-23 |
| 关联文档 | `组织与账号管理设计.md`、`研发交付全流程设计.md`、`ARCHITECTURE.md` |
| 设计目标 | 把组织成员分配到具体项目，并用项目角色约束审批、研发、测试、发布和成员管理 |

## 一、边界

组织角色解决“谁能管理组织和项目”，项目角色解决“谁参与哪个项目、在项目中承担什么责任”。

```text
全局账号
  → 组织成员（ORG_OWNER / ORG_ADMIN / PROJECT_MANAGER / ORG_MEMBER）
    → 项目成员（project_member）
      → 项目角色（产品、技术、测试、发布等）
```

同一个账号可以：

- 在不同组织拥有不同组织角色；
- 在不同项目拥有不同项目角色；
- 在同一个项目同时承担多个角色。

## 二、项目角色

| 角色代码 | 名称 | 主要职责 |
|---|---|---|
| `OWNER` | 项目负责人 | 项目成员、范围、风险和最终交付 |
| `BUSINESS_OWNER` | 业务负责人 | 业务目标、验收标准与价值确认 |
| `PRODUCT` | 产品负责人 | 需求与需求评审 |
| `TECH_LEAD` | 技术负责人 | 详细设计、设计评审和研发完成确认 |
| `ARCHITECT` | 架构师 | 架构方案、技术风险和设计评审 |
| `DEVELOPER` | 开发 | 编码、自测和代码审阅 |
| `QA` | 测试负责人 | 冒烟、自动化、转测、集成和回归 |
| `OPS` | 运维/SRE | 环境、部署、生产发布和运行观察 |
| `SECURITY` | 安全/合规 | 安全评审、合规检查和风险豁免 |
| `RELEASE_MANAGER` | 发布负责人 | 制品、发版评审和生产发布 |
| `VIEWER` | 观察者 | 只读查看项目信息 |
| `AUDITOR` | 审计员 | 只读检查门禁、审计和证据 |

`OWNER` 由项目创建时自动指定，不通过“添加成员角色”接口授予。

## 三、成员管理权限

以下角色可以管理项目成员：

- 项目负责人 `OWNER`；
- 项目所属组织的 `ORG_OWNER`；
- 项目所属组织的 `ORG_ADMIN`；
- 项目所属组织的 `PROJECT_MANAGER`。

普通组织成员、开发、测试等角色不能修改成员。

项目成员必须先是项目所属组织的成员。管理员只能从组织成员目录中选择人员，不能把组织外账号直接塞进项目。

## 四、页面行为

### 4.1 项目成员页

项目成员页包括：

- 当前项目名称、所属组织和成员数；
- 项目角色分布；
- 当前成员及其多个项目角色；
- 添加成员时从组织成员目录选择；
- 添加角色、移除角色；
- 项目负责人角色不可通过普通接口移除。

项目经理即使不是项目成员，也可以进入自己组织内项目的成员页进行人员分配，但不会因此自动获得项目业务审批权。

### 4.2 组织成员页

组织成员页每个成员显示：

- 组织角色；
- 已加入的项目；
- 在项目中的角色。

例如：

```text
张三
组织角色：项目经理
项目：Regent 平台 · 技术负责人、架构师
      App 审核 · 测试负责人
```

组织管理员只管理组织角色；项目角色仍在具体项目中维护。

## 五、服务端权限

项目成员查询和管理使用统一守卫：

```text
ProjectMembershipGuard
  ├─ requireReadable(projectId, actor)
  └─ requireManage(projectId, actor)
```

`requireManage` 接受：

- 项目成员中的 `OWNER`；
- 项目所有者字段对应的账号；
- 项目所属组织的组织所有者、组织管理员或项目经理。

成员候选列表接口只返回同一组织的成员，并附带：

- 组织角色；
- 当前项目角色；
- 用户公开资料。

## 六、研发门禁

研发流程继续只使用项目角色审批：

- 需求评审：产品负责人；
- 设计评审、研发完成：技术负责人；
- 冒烟、自动化、转测、集成、回归：测试负责人；
- 创建发布、发版评审、生产发布：发布负责人；
- 立项、取消交付、关闭发布：项目负责人。

组织管理员身份不能替代项目角色审批，避免组织管理者越权替业务负责人拍板。

## 七、当前版本边界

第一版已经完成：

- 12 个项目角色；
- 组织成员候选列表；
- 项目成员多角色分配；
- 项目负责人或组织管理者管理成员；
- 组织成员页展示项目归属和项目角色；
- 项目成员管理接口的服务端权限校验。

后续需要继续做：

- 将 `VIEWER`、`AUDITOR`、`OPS`、`SECURITY` 等角色接入任务、Bug、测试、部署的具体写权限；
- 项目负责人转移；
- 项目成员批量导入；
- 项目角色模板和角色矩阵配置；
- 多人会签和独立评审。
